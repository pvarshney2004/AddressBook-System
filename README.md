# AddressBook-System
## 📌 Project Description
This project is a **C# Address Book Management System** developed to practice Object-Oriented Programming, Collections, File Handling, CSV/JSON data processing, and structured software development using Git branches.

The application allows users to create, manage, search, sort, and store contact details efficiently while supporting multiple address books and different data storage formats such as files, CSV, and JSON.

The main objective is to strengthen practical skills in:

- OOP concepts in C#
- Collection Framework usage
- File IO operations
- CSV and JSON data handling
- Clean code practices and modular development
- Git branch-wise feature development

---

## 🎯 Implemented Use Cases (UC1 – UC15)

### UC1 – Create Contact
Ability to create a contact in the address book including personal
details such as name, address, phone number, email, etc.

### UC2 – Add New Contact
Add a new contact to the address book using console input
and proper object relationships.

### UC3 – Edit Existing Contact
Modify details of an existing contact using the person's name.

### UC4 – Delete Contact
Remove a contact from the address book using the person's name.

### UC5 – Add Multiple Contacts
Store multiple contacts using collection classes.

### UC6 – Multiple Address Books
Support multiple address books, each having a unique name,
managed using a dictionary.

### UC7 – Prevent Duplicate Contacts
Ensure no duplicate contact entry exists within the same
address book using equality checks.

### UC8 – Search by City or State
Search contacts across multiple address books based on
city or state.

### UC9 – View Contacts by City or State
Display contacts grouped by city or state using dictionaries.

### UC10 – Count Contacts by Location
Display the number of contacts grouped by city or state.

### UC11 – Sort by Name
Sort contacts alphabetically by person name using collections.

### UC12 – Sort by Location Fields
Sort contacts based on city, state, or ZIP code.

### UC13 – File IO Integration
Read and write address book data using file handling.

### UC14 – CSV Data Handling
Store and retrieve address book contacts using CSV files.

### UC15 – JSON Data Handling
Read and write address book contacts in JSON format.
